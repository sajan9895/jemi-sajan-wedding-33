SAJAN & JEMI WEDDING WEBSITE

Contents:
- index.html: mobile-friendly interactive wedding invitation page
- invitation.pdf: printable invitation PDF, embedded preview and download link

Features:
- Interactive question-and-answer experience
- Skip Ahead button
- Ceremony and reception map links
- Parents' names and addresses
- PDF preview and download

Important:
- The guest message box is a visual demo only; messages are not sent or stored.
- The site is not published yet. Vercel will create the public vercel.app URL after deployment.
- To deploy, upload these files to a GitHub repository and import that repository into Vercel.
